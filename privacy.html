隱私權政策 / Privacy Policy

最後更新 / Last updated: 2026-10-10

1. 這個工具是誰在用 / Who uses this app

xiaowkang-youtube 只由 YouTube 頻道 @Aianime-u1k 的擁有者本人使用，不開放其他使用者。

xiaowkang-youtube is used only by the owner of the YouTube channel @Aianime-u1k. It is not offered to anyone else.

2. 存取哪些資料 / What data is accessed

透過 Google OAuth，以唯讀權限 https://www.googleapis.com/auth/yt-analytics.readonly 讀取頻道擁有者自己頻道的 YouTube 分析報表，例如觀看次數、觀看時長、觀眾留存率與流量來源。

With the read-only scope yt-analytics.readonly, the app reads YouTube Analytics reports for the owner's own channel, such as views, watch time, audience retention and traffic sources.

3. 資料怎麼使用與存放 / How data is used and stored

資料只用來讓頻道擁有者了解自己頻道的表現。授權憑證與報表只存放在擁有者自己的電腦上，不會上傳到任何伺服器，也不會出售、分享或轉交給任何第三方。

Data is used only to help the owner understand their own channel's performance. Credentials and reports are stored only on the owner's computer, are not uploaded to any server, and are never sold, shared or transferred to any third party.

本工具對 Google API 取得之資料的使用，遵守 Google API Services User Data Policy，包括有限使用（Limited Use）規定。

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 撤銷存取 / Revoking access

可隨時到 Google 帳戶的第三方存取權 移除本工具的權限。

Access can be revoked at any time from Google Account third-party access settings.

5. 聯絡 / Contact

如有問題，請透過 YouTube 頻道 @Aianime-u1k 聯絡。

Questions can be sent via the YouTube channel @Aianime-u1k.
